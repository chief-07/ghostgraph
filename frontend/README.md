# GhostGraph Dashboard Frontend

The Tri-View interactive user interface for GhostGraph:
- **Panel A:** Interactive Retro Arcade Canvas (renders live gameplay executed by the reconstructed C engine).
- **Panel B:** Live Cytoscape.js Topology Graph (renders FalkorDB nodes and pulsed failure/success edges).
- **Panel C:** Autonomous Agent Reasoning Terminal (streams live Gemini Flash MCP tool calls and Cypher queries via SSE).
